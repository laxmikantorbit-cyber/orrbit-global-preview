# V1 Specification

## Modules
1. Authentication and owner access.
2. Project registry and environments.
3. Manual project onboarding.
4. AI-assisted project onboarding with plan-before-apply.
5. Existing project import.
6. AI development request analysis and impact plan.
7. Git feature branch/workspace management.
8. Build/test validation.
9. Preview deployments and revision requests.
10. Approval and controlled deployment.
11. Health verification and release evidence.
12. Rollback/version history.
13. Domains and DNS change proposals.
14. Secret references, never secret values in AI context.
15. Audit log and job history.
16. AI/cloud cost tracking and budgets.

## V1 non-goals
No AWS/Azure adapters, reseller billing, Kubernetes, full IDE, or drag-drop website builder in V1.
