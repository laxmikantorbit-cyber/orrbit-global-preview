# Panel Completion Rule

## Permanent project rule

The oRRbit AI Control Plane panel must be completed to 100% before any real SaaS product,
website, ChatGPT Sites project, repository transfer, source import or migration is executed.

This includes, without exception:
- Martial Arts ERP or future sports products
- oRRbit.in
- orrbitrepair.com
- any future SaaS, website or customer project

## Development rule

Before panel completion:
- Synthetic/test fixtures may be used only for QA of panel mechanics.
- Synthetic fixture requests must be explicitly marked as synthetic.
- Real source packages, production migrations and real transfer execution are blocked.
- Production, DNS, live payment, live database and customer-data operations remain protected.
- Completing an import-related panel module does not authorize using it on a real project.

## Unlock rule

Real import/transfer remains locked until:
1. Every required panel module is marked ready.
2. The panel readiness gate reports 100% completion.
3. The control-plane completion flag is explicitly enabled after owner approval.

The backend gate is authoritative even if a UI control is bypassed.
