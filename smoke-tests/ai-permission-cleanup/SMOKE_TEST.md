# AI Permission Cleanup Planner — Smoke Test

## Hypothesis
SMB IT admins/MSPs will pay for a local Windows tool that goes beyond NTFS permission reporting and produces a safe, explainable cleanup plan.

## Core wedge
Audit/reporters show current ACLs. Enterprise suites remediate but are expensive/heavy. This product targets the middle: effective-access analysis + risk prioritization + read-only remediation planning + reversible change scripts.

## Proposed price test
Admin $199 one-time; Consultant $349 one-time; Team $599 one-time.

## Pass metrics
1. >= 8% of qualified landing visitors open Pricing.
2. >= 3% of qualified landing visitors reach Interest.
3. >= 5 credible sysadmin/MSP conversations confirm cleanup planning is more valuable than another report.
4. At least 2 buyers indicate willingness around $199+ without requiring enterprise integrations.

## Kill metrics
Interest <1% after meaningful qualified traffic; buyers only want free reporting; remediation requires enterprise integrations; or users will not trust read-only AI-assisted plans enough to pay.

## Safety
V1 stays read-only. Deterministic Windows ACL logic is authoritative; AI explains and prioritizes. No automatic production permission changes.
